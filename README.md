# java-new-features

Runnable samples of new Java features, one directory per Java version.

| Version | Directory | Article |
| --- | --- | --- |
| Java 17 (LTS) | [java17](java17/) | [日本語](https://blog.issyuu.com/post/java17-new-features/) / [中文](https://blog.issyuu.com/zh/post/java17-new-features/) / [English](https://blog.issyuu.com/en/post/java17-new-features/) |
| Java 21 (LTS) | [java21](java21/) | [日本語](https://blog.issyuu.com/post/java21-new-features/) / [中文](https://blog.issyuu.com/zh/post/java21-new-features/) / [English](https://blog.issyuu.com/en/post/java21-new-features/) |
| Java 25 (LTS) | [java25](java25/) | [日本語](https://blog.issyuu.com/post/java25-new-features/) / [中文](https://blog.issyuu.com/zh/post/java25-new-features/) / [English](https://blog.issyuu.com/en/post/java25-new-features/) |

More versions will be added.

- Each sample is a single file that runs with `java <File>.java` (no build tool needed).
- Comments are in Japanese, Chinese and English; output is in English.

## 日本語

Java の新機能を動かして確かめるサンプル集。Java のバージョンごとにディレクトリを分けている（現在は Java 17、Java 21、Java 25）。

## 中文

用来实际运行、验证 Java 新特性的示例集，按 Java 版本分目录（目前有 Java 17、Java 21、Java 25）。
